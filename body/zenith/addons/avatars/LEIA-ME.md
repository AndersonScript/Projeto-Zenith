# Avatares

O repositório público NÃO traz avatar: a licença de cada modelo .vrm precisa ser conferida antes de redistribuir.

**Zenith 1.0 Oficial** — o mascote oficial se chama `Zenith.vrm` e ainda está sendo desenhado. Quando ele existir,
coloque o arquivo com esse nome exato NESTA pasta e abra o projeto no Godot uma vez (é o que gera o `.vrm.import`).
No dia em que ele chegar, ele passa a ser o padrão de todo mundo; até lá a pasta vai vazia e o Corpo desenha o
visual padrão do código (`vrm_model_path` vazio não é erro). Os avatares prontos de terceiros que estavam aqui
saíram da distribuição por licença.

Para usar um avatar só seu, coloque aqui o SEU modelo `.vrm` (que você criou ou que permita redistribuição) e abra o
projeto no Godot uma vez para ele ser importado.

O arquivo do avatar que vem no pacote tem um nome de arquivo interno histórico — ele não aparece para quem usa o
programa. Para renomear pelo editor (sem quebrar a cena), siga `docs/RENOMEAR_INTERNOS_GODOT.md`.
